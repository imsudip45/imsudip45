Full Stack Engineer at Nullion Technologies (since May 2026), based in Birtamod, Nepal. I build web applications with Python (FastAPI, Django REST Framework) and TypeScript (Next.js, React).

### Projects

- **[Persona](https://github.com/tmgnisc/Ai-builder-cup)**: an e-commerce platform with an AI shopping companion, Pip, that moves around the page with the shopper, compares products and hands work to a small team of AI sub-agents. Team project for the AI Builder Cup.
- **[Labya_compute](https://github.com/imsudip45/Labya_compute)**: a GPU rental marketplace where hosts share idle GPUs through Docker containers and reverse SSH tunnels. College project with Sugam Dahal and Saurab Prasai; I later rewrote the backend in FastAPI.
- **[Fingerprint](https://github.com/imsudip45/Fingerprint)**: a voice tutor for children built on the Gemini Live API, with a planner that adds pictures, quizzes and worked examples. My entry to the Google Gemini API Developer Competition.
- **[Football Score Pro](https://github.com/imsudip45/football-score-pro)**: desktop software for running a football match broadcast: squads, officials, clock, goals, cards, substitutions and penalty shootouts. Built in Python and PySide6 at FutureFrame, with a FastAPI match API that keeps a web dashboard in sync over WebSockets.
- **[Football Score Lite](https://github.com/imsudip45/football-score-lite)**: live match graphics for football and futsal streams, pushed over WebSockets to a page that OBS captures. Electron and Next.js, built at FutureFrame.
- **[Thrill-Binge](https://github.com/imsudip45/Thrill-Binge)**: a movie browsing site built with Next.js, Django REST Framework and the TMDB API.
- **[litert-image-classifier](https://github.com/imsudip45/litert-image-classifier)**: an image classifier that runs entirely in the browser with LiteRT.js and WebGPU ([live demo](https://imsudip45.github.io/litert-image-classifier/)).
